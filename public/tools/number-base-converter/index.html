What is the Number Base Converter?

Convert integers between binary, octal, decimal and hexadecimal. Use it for a quick, transparent result, then review the method and boundaries below before relying on the answer.

How it works

A positional numeral equals the sum of each digit multiplied by its base raised to the digit position.

The calculator keeps full precision during the calculation and rounds the displayed result for readability.

Practical example

Decimal 255 equals binary 11111111 and hexadecimal FF.

How to use this in Excel

Place the inputs in the cells referenced below, enter the formula, and apply the appropriate number format.

=DEC2BIN(A2), =DEC2HEX(A2), =BIN2DEC(A2)

Review units and cell references before copying the formula down a worksheet.

Common mistakes and limitations

  • Entering digits that are invalid for the selected base.
  • Confusing hexadecimal letter O with zero.
  • Assuming signed values use the same representation in every system.

Important limitation: This version handles integers within JavaScript safe-integer limits and does not convert fractional values.
