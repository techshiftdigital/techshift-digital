What is the Percentage Change Calculator?

Calculate the percentage increase or decrease from an original value to a new value. Use it for a quick, transparent result, then review the method and boundaries below before relying on the answer.

Formula

Percentage change = ((new value − original value) ÷ original value) × 100

The calculator keeps full precision during the calculation and rounds the displayed result for readability.

Practical example

A value rising from 80 to 100 has a change of ((100 − 80) ÷ 80) × 100 = 25%. A fall from 100 to 80 is a 20% decrease because the baseline is different.

How to use this in Excel

Place the inputs in the cells referenced below, enter the formula, and apply the appropriate number format.

=(B2-A2)/A2

Review units and cell references before copying the formula down a worksheet.

Common mistakes and limitations

  • Dividing by the new value instead of the original baseline.
  • Confusing percentage change with percentage difference.
  • Assuming a 25% increase followed by a 25% decrease returns to the starting value.

Important limitation: A zero original value makes percentage change undefined. Negative baselines can produce signs that need interpretation in context.
