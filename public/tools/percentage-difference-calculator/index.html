What is the Percentage Difference Calculator?

Compare two values symmetrically when neither value is the original baseline. Use it for a quick, transparent result, then review the method and boundaries below before relying on the answer.

Formula

Percentage difference = |A − B| ÷ ((|A| + |B|) ÷ 2) × 100.

The calculator keeps full precision during the calculation and rounds the displayed result for readability.

Practical example

The percentage difference between 80 and 100 is 22.22%.

How to use this in Excel

Place the inputs in the cells referenced below, enter the formula, and apply the appropriate number format.

=ABS(A2-B2)/AVERAGE(ABS(A2),ABS(B2))

Review units and cell references before copying the formula down a worksheet.

Common mistakes and limitations

  • Using one value as the baseline.
  • Dropping the absolute value.
  • Calling a directional increase a percentage difference.

Important limitation: When both values are zero the result is undefined. This measure is not the same as percentage change.
