What is the Random Number Generator?

Generate one or more random integers inside an inclusive range. Use it for a quick, transparent result, then review the method and boundaries below before relying on the answer.

How it works

Each integer is selected uniformly from minimum through maximum using the browser random source.

The calculator keeps full precision during the calculation and rounds the displayed result for readability.

Practical example

With a minimum of 1 and maximum of 6, the tool simulates a six-sided die.

How to use this in Excel

Place the inputs in the cells referenced below, enter the formula, and apply the appropriate number format.

=RANDBETWEEN(A2,B2)

Review units and cell references before copying the formula down a worksheet.

Common mistakes and limitations

  • Setting the minimum above the maximum.
  • Assuming a small sample must look evenly distributed.
  • Using non-cryptographic randomness for security.

Important limitation: Browser-generated values are suitable for everyday sampling but should not be used for lotteries, cryptographic keys or regulated draws.
