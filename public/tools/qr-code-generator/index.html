QR Code Generator

Generate and download a QR code PNG for a URL or short text, entirely in your browser.

Enter your values and select generate qr code.

How this tool works

QR codes encode the text or URL you enter into a scannable square matrix. Leave a clear quiet zone around the code and test it with a phone before distributing.

Important limitations

Maximum input is 700 characters; very long text may not fit. This generates a static QR code and does not offer analytics or editable redirects.
