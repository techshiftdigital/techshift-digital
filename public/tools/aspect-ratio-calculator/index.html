Aspect Ratio Calculator

Find a simplified aspect ratio and proportional height or width for images and displays.

Enter your values and select Calculate.

How it works

Simplify width:height using the greatest common divisor. New height = new width × original height ÷ original width.

Important limitations

Proportional resizing preserves shape, not image quality.
