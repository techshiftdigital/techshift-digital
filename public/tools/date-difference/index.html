Date difference calculator

Measure elapsed calendar days between two dates.

Enter your values, then select the action above.

How elapsed days are counted

This tool subtracts the start date from the end date. The same date returns zero; the following day returns one. It uses calendar dates rather than local clock hours.

Excel formula: =B2-A2, with the result formatted as a number.

Important boundaries

The start day is not counted as an additional day. The end date must be on or after the start date.
