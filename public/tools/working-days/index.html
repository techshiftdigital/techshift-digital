What is the Working Days Calculator?

Count weekdays between two dates, with an option to include the start and end dates. Use it for a quick, transparent result, then review the method and boundaries below before relying on the answer.

Formula

Working days = included calendar days − Saturdays − Sundays. Public holidays are not removed unless handled separately.

The calculator keeps full precision during the calculation and rounds the displayed result for readability.

Practical example

Monday through the following Friday contains 5 working days when both endpoints are included.

How to use this in Excel

Place the inputs in the cells referenced below, enter the formula, and apply the appropriate number format.

=NETWORKDAYS(A2,B2)

Review units and cell references before copying the formula down a worksheet.

Common mistakes and limitations

  • Forgetting whether endpoints should be included.
  • Assuming every country follows a Monday–Friday workweek.
  • Calling weekdays business days without subtracting public holidays.

Important limitation: This version excludes Saturdays and Sundays but does not know regional public holidays. Use a holiday range in Excel when needed.
