Working days calculator

Count Monday-to-Friday workdays, with optional holiday exclusions.

Enter your values, then select the action above.

How working days are counted

The calculation includes both start and end dates, excludes Saturdays and Sundays, and removes any weekday holidays you enter. Duplicate holiday dates count once.

Excel equivalent: =NETWORKDAYS(A2,B2,H2:H10), where the final range contains holiday dates.

Important boundaries

This is a Monday-to-Friday calendar, not a country-specific employment calendar. Add relevant holidays yourself. Date ranges are limited to 100 years.
