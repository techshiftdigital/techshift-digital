Como usar

Um utilitário prático no navegador para verificações rápidas, planejamento e trabalho mais claro. Insira os valores, revise o resultado e mantenha as premissas com seu registro.

  1. Insira cuidadosamente os valores de origem.
  2. Selecione as opções necessárias e execute o cálculo.
  3. Revise o resultado, a fórmula e o exemplo antes de usá-lo em uma decisão.

Fórmula

The method used by this tool is count normalized occurrences of each word. Keep the source values and units with the result so another person can reproduce the calculation.

Exemplo resolvido

data data insight → data: 2; insight: 1. This example demonstrates the sequence; your result depends on the values and options you enter.

Orientação para Excel

Use this workbook approach: =LET(w,TEXTSPLIT(LOWER(A2)," "),u,UNIQUE(w),HSTACK(u,COUNTIF(w,u))). Format percentage results as Percentage, dates as dates, and financial values with the correct currency. Avoid rounding intermediate steps.

Perguntas frequentes

Esta ferramenta envia meus dados?

Não. O cálculo é executado localmente no seu navegador.

Posso usar o resultado em trabalho profissional?

Use-o como estimativa verificada. Confirme dados, unidades, datas e regras antes de depender dele.

Por que o Excel pode mostrar outro resultado?

As diferenças geralmente vêm de arredondamento, sistemas de data, formato percentual ou premissas diferentes.

Posso favoritar esta página?

Sim. A URL é estável, mas os valores não são salvos ao sair.
