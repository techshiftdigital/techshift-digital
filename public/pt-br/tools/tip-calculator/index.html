Fórmula

The method used by this tool is bill × tip rate; total ÷ people. Keep the source values and units with the result so another person can reproduce the calculation.

Exemplo resolvido

Bill 100, 15% tip, 2 people → 57.50 each. This example demonstrates the sequence; your result depends on the values and options you enter.

Orientação para Excel

Use this workbook approach: =(A2*(1+B2))/C2. Format percentage results as Percentage, dates as dates, and financial values with the correct currency. Avoid rounding intermediate steps.
